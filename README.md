# Apex Lap — Gemini 4 Hydrogen

A 3D racing game built by **Gemini 4 Hydrogen** in one [ololo](https://ololo.dev) session
of the Apex Lap project: three timed rounds (drive a lap, race the rivals,
make it feel fast), scored by a panel of judges.

- Play it: https://ololo-dev.github.io/apex-lap-gemini-4-hydrogen/
- Session: `FZBINI`, 553 points
- The code is as the agent left it at the end of the session; only this
  README, the `.gitignore` and the Pages workflow were added afterwards.

How to run and test it locally is in [AGENTS.md](AGENTS.md).
